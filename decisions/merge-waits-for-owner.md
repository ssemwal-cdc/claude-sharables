# Every merge waits for the owner

**Rule.** No standing merge grant exists. Every merge waits for the owner's word, for that pull request. A past approval does not count.

**Outcome protected.** The owner decides what ships to every teammate.

**Argument.**

The owner ruled this on 2026-10-15. An earlier standing grant to merge once CI passed is withdrawn. The parent rule git-main-only-by-pr says the owner names the merge act, unless a repo grants it. This repo grants nothing.

Process-only ruling. It changes how sessions work, not the shipped product.

**Evidence.**

- Ruled by the owner on 2026-10-15.

**Checks.** none
