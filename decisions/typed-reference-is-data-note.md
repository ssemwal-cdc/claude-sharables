# A typed reference is data

**Rule.** Report a disagreeing typed reference as a data-entry note. Never flag an item on it.

**Outcome protected.** A real data-quality problem is told to the right people without inventing a money claim.

**Argument.**

A typed reference that disagrees with the linkage is a data-entry problem, not a misallocation.

Report it. A wrong reference field is worth telling the accounts payable team.

It never flags an item on its own and never produces a sentence about money on the wrong purchase order.

The signal was real. Only its category was wrong.

  comes from linkage.
