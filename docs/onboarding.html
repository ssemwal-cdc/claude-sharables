Approval Plugin Setup

Two plugins that review your NetSuite and Procore approval queues and publish a read-only dashboard.

1. Install the plugin

Add the marketplace ssemwal-cdc/claude-sharables, then install netsuite-approval-review, procore-open-items-review, or both. Setup, setup advice and the daily schedule are handled by the skill itself, on its first run.

2. Ask for a review

Say "run my approval check" for NetSuite, or "run my Procore review" for Procore. Each skill walks you through anything else it needs.

Full install steps and troubleshooting are in the repo README.

The plugins update from ssemwal-cdc/claude-sharables.
