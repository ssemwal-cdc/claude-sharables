# Permission mode is unreadable

**Outcome protected.** A permission question converges in one round instead of three.

**Argument.**

No tool reports the permission mode of the session.

So the question of which mode a run was in is unanswerable after the fact.

It can only be recorded by the person at the keyboard, at the time.

Capture the mode at the moment of the run if a permission question ever comes up again. Everything else follows from that one fact.

Without it no amount of probing converges.

**Evidence.**

- Three rounds of investigation and two wrong versions of the permissions note rested on a mode remembered afterwards.
- Recorded 2026-08-15.

**Checks.** none
