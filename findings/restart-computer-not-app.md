# Restart the computer

**Outcome protected.** A teammate sees a plugin install or update without running a command.

**Argument.**

An app restart is not reliably enough for a plugin install or update to appear.

Updates land on the next reboot. For most people that is the following morning.

So auto sync plus a normal work rhythm needs no commands at all.

**Evidence.**

- Observed on Windows. The failure count and the conditions are `unmeasured`.
- Stated in `docs/onboarding.html`.

**Checks.** none
